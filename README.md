## 🧩 TakeBridge — What I’m Building  

> **TakeBridge** is an AI coworker that completes busywork across your apps by *seeing* your screen, understanding UI context, and using both GUI control + APIs.

- 🧠 Multimodal agent that combines vision, text, and tool calls  
- 🖥️ Operates in a dedicated Ubuntu workspace (VM) with your existing apps  
- ⚙️ Uses **GUI actions** *and* **MCP/API tools** (Gmail, Slack, Sheets, dashboards, internal tools)  
- 📊 Focused on automating: reporting, data entry, CRM updates, email workflows, back-office ops  

🔗 **Check it out:** https://takebridge.com/
